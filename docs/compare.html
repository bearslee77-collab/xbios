XBIOS 1.0
기존 MSX BIOS 와 무엇이 다른가

가장 큰 차이는 BASIC 대신 파이썬이 들어 있다는 점입니다.

한 장으로 보면

회색은 원래 제조사 코드, 파란색은 XBIOS 로 바꾼 것, 보라색은 MSX BASIC 을 대신한 파이썬(XPY), 초록색은 한글 SCREEN 9 입니다.

다섯 가지 차이

1

BASIC 대신 파이썬 (XPY)

켜면 Ok 대신 >>> 가 뜹니다.

2.3배BASIC 대비 속도
2

어느 기종에서나 한글

한국 기종이 아니어도 SCREEN 9 한글과 두벌식 입력이 됩니다.

몇 배한글 출력 속도
3

기존 코드 없음

기존 BIOS 의 코드를 쓰지 않았습니다.

CCBY-NC-ND 4.0
4

네 세대를 한 소스에서

MSX1 · MSX2 · MSX2+ · turbo R 을 같은 코드에서 만듭니다.

4세대
5

기존에 없던 기능

FM 음원 진입점, VDP 로 그리는 원·상자·칠하기, turbo R 의 R800 전용 연산.
