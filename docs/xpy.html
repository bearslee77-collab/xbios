XPY 명령어 해설

XBIOS 1.0 · XPY version 1.0

형 · 내장 함수 · 모듈별 함수
차 례1. 사용 방법2. 지원하는 형과 문법3. 내장 함수4. screen: 화면과 그리기5. sprite6. sound7. key, joy, pad8. mem: 메모리, I/O, BIOS9. fs: 디스크10. time11. turbo: turbo R 전용12. sys13. random14. math15. 확장 칩 모듈

이 문서는 XPY에서 쓸 수 있는 형, 내장 함수, 모듈과 함수를 정리한 참고서입니다.

1사용 방법

  • 모듈은 모두 내장되어 있어서 import 없이 이름으로 바로 씁니다. 예: screen.pset(10, 20)
  • 좌표는 항상 왼쪽 위가 (0, 0)입니다.
  • 인수를 생략할 수 있는 자리의 기본값은 None이며, 현재 설정을 그대로 쓴다는 뜻입니다. screen.color(0)은 전경색을 검정으로 바꾸고, screen.color(None)은 바꾸지 않습니다.
  • 범위를 벗어난 인수는 ValueError, 형이 맞지 않으면 TypeError, 그 기계에서 지원하지 않는 기능은 NotImplementedError, 디스크 오류는 OSError, 메모리 부족은 MemoryError가 발생합니다. Ctrl-STOP은 KeyboardInterrupt가 됩니다.
  • 세대 표기는 MSX1, MSX2, MSX2+, turbo R 입니다. 표기가 없는 함수는 모든 세대에서 동작합니다.
  • 일부 이름은 실행 환경에 따라 들어 있지 않을 수 있습니다. 해당 항목에 따로 적었습니다.

2지원하는 형과 문법

형

형설명
int부호 있는 32비트 정수 (−2147483648 ~ 2147483647)
float단정도(32비트) 실수. 유효 숫자는 약 7자리입니다
boolTrue, False
str바이트열입니다. 유니코드가 아니므로 len("가")는 2입니다
None값 없음
list가변 배열
dict사전 (넣은 순서를 유지합니다)

튜플과 bytes 형은 없습니다. 여러 값을 돌려주는 함수는 리스트를 돌려줍니다. VRAM이나 메모리에서 읽은 바이트열은 str로 돌려줍니다.

문장과 연산자

  • 문장: if/elif/else, while, for/in, break, continue, pass, def, return, global, try/except/finally, raise, del, assert
  • 연산자: + - * / // % ** << >> & | ^ ~, 비교 == != < <= > >=, 논리 and or not, in, not in
  • a, b = b, a 같은 두 값의 교환 대입을 쓸 수 있습니다.
  • / 는 실수 나눗셈, // 는 정수 나눗셈입니다. 0으로 나누면 ZeroDivisionError가 발생합니다.
  • class, yield, with, lambda, import, 데코레이터는 지원하지 않습니다.
  • f-문자열은 {식}과 {식:서식} 형태를 지원합니다. !r, =, 서식 안의 {} 중첩은 지원하지 않습니다. f-문자열과 format()이 들어 있지 않은 환경에서는 NotImplementedError가 발생합니다.

format 서식

[[채움]정렬][부호][0][너비][.자리수][형] 형태입니다.

  • 정렬: <, >, ^, = (=는 수에만 씁니다)
  • 부호: +, -, 빈칸 (문자열에는 쓸 수 없습니다)
  • 형: d, s, f 또는 생략. f의 기본 소수 자리는 6이고 반올림은 0.5에서 짝수 쪽으로 합니다.
  • x, o, e, g, %와 천 단위 구분은 지원하지 않으며 ValueError가 발생합니다.
【보기】
print(f"SCORE{s:5}  HI-SC{h:5}")
print(format(3.14159, ".2f"))     # 3.14

turbo.xform, turbo.rayview, turbo.raycast, screen.rotozoom은 이 이름이 들어 있는 실행 환경에서만 쓸 수 있습니다.
